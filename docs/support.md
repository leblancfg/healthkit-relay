# Help and support

Health Relay copies your Apple Health data to a server you run yourself. Most questions are
answered in these pages:

- **Setting up a server:** [Quick start](quickstart.md) (Docker, a single binary, NixOS,
  a NAS or a Raspberry Pi; about ten minutes).
- **Pairing the iPhone:** [Pairing an iPhone](pairing.md). On the server's setup page, scan
  the QR code with the iPhone's Camera, or in the app tap **Enter Server Details Instead**
  and type the server address and the setup code shown under the QR code.
- **Reaching the server from the iPhone, HTTPS:** [Networking & HTTPS](networking.md).
- **Syncing:** the app syncs in the background several times a day; open the app to sync
  right away. iPhone keeps Health data locked while the phone is locked, so background syncs
  happen after you unlock it. More in [Troubleshooting](troubleshooting.md).
- **Your data:** [Privacy policy](privacy.md) and [Security & privacy](security.md).

## Contact

Write to [healthrelay@leblancfg.com](mailto:healthrelay@leblancfg.com). To help us help you,
include the app's version (**Advanced**, at the bottom), the server's version (on its setup
page), and, if a sync fails, the diagnostic log (**Advanced › Share Diagnostic Log**: sync
steps and counts, without Health values). We answer within a few days.
